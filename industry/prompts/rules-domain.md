
【股票/财经领域翻译规则 — 本平台 100% 是股票市场内容，严格遵守】

1. 歧义默认值：以下词在中文有非财经歧义，**一律按股票/财经含义翻译**：
   - Security / Securities = 证券（绝不译"安全"）
   - Stock = 股票（不译"库存"）
   - Share(s) = 股份/股票（"share of..."表示占比时除外）
   - Bond = 债券（不译"纽带"）
   - Treasury = 美国国债/美国财政部（按语境；不译"宝库"）
   - Fed / FOMC = 美联储 / 联邦公开市场委员会
   - Rate hike / cut = 加息 / 降息（不译"加息打击"等）
   - Guidance = 业绩指引（不译"指导"）
   - Buyback / Repurchase = 回购
   - Stake = 股权/持股（不译"赌注"）
   - Position = 仓位/持仓（不译"位置"）
   - Long / Short = 做多/做多看涨、做空/看跌（不译"长/短"）
   - Margin call = 追加保证金通知（不译"边距呼叫"）
   - Short squeeze = 轧空（不译"空头挤压"字面也接受，优先"轧空"）
   - Coverage = 评级覆盖（券商语境；不译"覆盖率"）
   - Placement = 配售（新股配售；不译"安置"）
   - Lock-up = 限售/锁定期
   - flotation/listing = 上市
   - Tender offer = 要约收购
   - Proxy = 委托书（股东大会语境）
   - Blue chip = 蓝筹股
   - Bull / Bear = 牛市/多头、熊市/空头

2. 以下专有名词**一律保留英文原文**，不翻译不加中文括注：
   - 指数（举例 + 通用规则）：S&P 500 / Nasdaq / Dow Jones / Russell 2000 / STOXX 50 / Nikkei 225 / Hang Seng（可写"恒生指数（Hang Seng）"首次）
     **规则**：指数英文名一律保留；常见的中文名（纳指、道指、标普500、恒指）可直接用中文
   - 公司（通用规则）：任何海外上市公司名保留英文原名或使用市场通用中文译名，保持全文一致（NVIDIA、Tesla、Apple、Microsoft、Amazon、Palantir、ARM、TSMC 等；台积电、特斯拉等通用译名可用）
   - 财报与会计缩写：EPS / PE / PB / ROE / ROA / EBITDA / GAAP / Non-GAAP / QoQ / YoY / ARR / CFO / COGS
   - 监管与文件：SEC / 10-K / 10-Q / 8-K / 13F / 13D / 13G / S-1 / F-1 / ADR / GDR / Form 4
   - 指数编制与资金：MSCI / FTSE / S&P Dow Jones Indices / QFII / QDII / ETF / LOF / REITs / VIX
   - 交易与衍生品：CME / CBOE / Options / Futures / Swap / IPO / SPAC / A股 / B股 / 港股通（中文名直接用）
   - 产业链术语：GPU / HBM / CoWoS / AI 算力（术语按行业惯例，AI 相关术语沿用行业写法）

3. 中国公司**优先用官方中文简称**（首次出现可双标"贵州茅台（600519.SH）"，后续选一种保持一致）：
   - 贵州茅台 / 宁德时代 / 比亚迪 / 中芯国际 / 腾讯控股（700.HK）/ 阿里巴巴（9988.HK / BABA）/ 美团（3690.HK）/ 工商银行 / 中国平安 / 长江电力 / 中际旭创 / 立讯精密
   - 港股、美股上市的中概公司用其官方中文名（腾讯控股、阿里巴巴、拼多多、网易、京东、百度、哔哩哔哩）

4. 代码 / 数字 / 单位 **一字不改**保留：
   - 股票代码不翻译：600519.SH、00700.HK、NVDA、BABA 原样
   - 数字+单位：市值 $3.2T / 2.5万亿港元 / 涨幅 +12.5% / P/E 28x / 成交额 1.2B 股 / LPR 3.0% / 33350 点
   - 金额、比例、点位必须保留原文的阿拉伯数字和单位；不要把 $10B-$100B 改写成“数十亿至数千亿美元”等中文数量词
   - 涨跌方向与幅度一字不改：不得把"下跌 5%"写成"波动 5%"，不得改写涨跌方向
   - 日期与财报期：Q1 FY2026 / 2026 财年 / 中报、三季报按原文保留
